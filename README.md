# ludobot-explainers

Анимированные ролики об исследованиях торгового бота Ludobot. Статические страницы на GitHub Pages.

- `hypotheses-week/` — «Неделя гипотез» (02.10.2026): 11 сцен, озвучка Grok Voice TTS (Ara) или голос браузера.
- `daily-desk-v2/` — «Daily Desk v2» (07.10.2026): тот же процесс за пять минут, 14 сцен, простые формулировки. Текст озвучки проходит проверку при сборке и чистится в плеере: голос получает только слова и обычную пунктуацию, без кавычек, тире, скобок, слэшей, цифр и латиницы.
- `daily-desk/` — «Daily Desk» (07.10.2026): рутины A и B, проверки бота, вход и выход, плюсы, минусы и рекомендации. 21 сцена, озвучка голосом браузера (русский синтез речи), субтитры, одна самодостаточная страница.

Дневник исследования, а не торговый сигнал и не инвестиционная рекомендация.
